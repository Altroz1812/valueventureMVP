## Safe use on Windows

1. Extract `ValuationPro_Source_Cleaned_2026-11-10.zip` to a NEW folder (for example `D:\ValuationPro_Source_Cleaned`). **Do not overwrite `D:\valuationpro-workspace-main` yet**.
2. Copy `.env.example` to `.env`, then use your own existing **public/publishable** Supabase configuration. Never put service-role/secret keys in a browser environment file.
3. `npm ci`, then `npm run dev`, `npx tsc --noEmit`, `npm run build`, `npm test` and the two source checks above.
4. With authorized test users, verify ADASOL/ADASOLB isolation, Case Creation, Field Officer edit and save, Field QC, Voice to Text, Reports and Billing.
5. Compare any differences from your current Windows workspace before selectively replacing files. This ZIP is cleaned from the **uploaded archive**, not from the latest unsupplied edits on your PC.
